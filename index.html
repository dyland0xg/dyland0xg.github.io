Optoelectronics

This project is a Python-based real-time target detection and dynamic tracking system designed for optronics, including drones, surveillance, and IR/thermal sensors. Powered by OpenCV and Ultralytics YOLOv8, it assigns unique persistent IDs to objects across live video streams or file inputs. The system offers high-speed, low-latency processing and allows seamless swapping to custom thermal models.
